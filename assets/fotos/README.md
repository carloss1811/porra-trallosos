# Fotos de los trallosos

Sube aquí una foto por participante y aparecerá sola en la web (podio,
clasificación y predicciones). Mientras no haya foto se enseña un círculo
con sus iniciales.

## Cómo se llama el archivo

El nombre del participante **tal y como lo puso en el formulario**, pero:

- todo en minúsculas
- sin tildes ni eñes (ñ → n)
- espacios y símbolos sustituidos por guiones `-`

Formato: `.jpg` o `.png` (si existen los dos, gana el `.jpg`).

| Participante | Archivo |
|---|---|
| `Tete` | `tete.jpg` |
| `Don Chorlito` | `artem.jpg` |
| `El Refresco` | `pozuelikol.jpg` |
| `YO NO FUI FUE EL VAR` | `no-es-locura-es-agricultura.jpg` |

## Consejos

- Mejor fotos **cuadradas** (se recortan en círculo).
- Con 200×200 px sobra; no subas fotos enormes para que la web cargue rápido.
